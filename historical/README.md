# Historical Archive Boundary

`A2_RAG_QA-main.legacy-2026-07-15.zip` is a preserved source archive of a
divergent legacy implementation. It is not runnable in place, is excluded from
release packages and project audits, and must not be deployed or evaluated as
the active system. Its SHA-256 sidecar records the archived bytes.

The active implementation is the repository root. The legacy archive is kept
only because the local `.git` directory contains no usable history and deleting
the divergent copy outright would destroy review evidence.

`stale-reports/` contains quarantined PDFs with retired implementation and
performance claims. Those files are historical evidence only and are also
excluded from releases.
